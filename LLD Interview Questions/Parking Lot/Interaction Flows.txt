1. Entry Flow
    - Driver Enters
    - Get a slot
    - Get a Ticket

2. Exit Flow
    - Driver Exits
    - Shows the ticket
    - Price Computed ( minimum of FLAT and HOURLY Pricing )
    - Pays the amount ( Retry if fails )
    - Get the receipt
    - Slot is released
    - Ticket deactivated ( to avoid multiple entries )


3. Admin Flow
    - Requests to add a floor
    - Requests to add slots
    - Requests to update pricing
